## ui-sdk

The app in `app/` uses ui-sdk (`@ui-sdk/svelte`, `@ui-sdk/core`). Before you use ui-sdk:

1. Follow the `ui-sdk` skill if it is installed.
2. Read `app/node_modules/@ui-sdk/svelte/docs/llms.txt`.

To build a new component, also search `app/node_modules/@ui-sdk/svelte/docs/core.md` by heading, and read `rendering.md` in the same folder.
