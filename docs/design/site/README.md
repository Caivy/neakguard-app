# NeakGuard Website review

The screenshots show the NeakGuard Website from `site/`, in English at 1440 pixels
wide and in Khmer at 390 pixels wide. Chromium took them with reduced motion.

- `before-*.png`: the first draft. "How it works" has three cards in one row, and
  the Download button opens the GitHub release page.
- `after-*.png`: this version. Each "How it works" step has its own band, with a
  picture and three points. The Download button downloads the 64-bit installer
  directly.
